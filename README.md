# Python & Git 기초 퀴즈 게임

## 1. 프로젝트 개요

코디세이 Python 학습 미션을 위한 콘솔 기반 퀴즈 게임입니다.

사용자는 Python과 Git의 기초 개념을 퀴즈로 학습하고, 새로운 문제를 직접 추가하거나 최고 점수를 확인할 수 있습니다.

## 2. 퀴즈 주제와 선정 이유

- **주제:** Python 및 Git 기초 개념
- **선정 이유:** 프로그램 개발에 필요한 Python 문법과 Git 명령어를 퀴즈로 복습하기 위해 선정했습니다.
- **기본 문제:** Python 5문제, Git 3문제 등 총 8문제
- 사용자가 직접 새로운 퀴즈를 추가할 수 있습니다.

## 3. 개발 환경

- 운영체제: Windows
- 개발 도구: Visual Studio Code
- 프로그래밍 언어: Python 3.10 이상
- 버전 관리: Git / GitHub
- 외부 라이브러리 사용 없음
- 데이터 저장 방식: UTF-8 JSON 파일

## 4. 실행 방법

1. 프로젝트 폴더를 VS Code로 엽니다.
2. VS Code에서 터미널을 실행합니다.
3. 프로젝트 최상위 폴더에서 다음 명령어를 실행합니다.

```powershell
python main.py
```

4. 화면에 표시되는 메뉴에서 1~5번을 선택합니다.

### 프로그램 메뉴

1. 퀴즈 풀기
2. 퀴즈 추가
3. 퀴즈 목록
4. 최고 점수 확인
5. 종료

## 5. 주요 기능

### 퀴즈 풀기
- 등록된 객관식 퀴즈를 순서대로 출제합니다.
- 각 문제에는 선택지 4개가 제공됩니다.
- 정답과 오답을 판정하고 최종 점수를 계산합니다.

### 퀴즈 추가
- 새로운 문제와 선택지 4개를 입력할 수 있습니다.
- 정답 번호는 1~4 중에서 선택합니다.
- 등록한 문제는 JSON 파일에 저장됩니다.

### 퀴즈 목록
- 현재 등록된 문제 제목을 순서대로 출력합니다.
- 전체 문제 개수를 확인할 수 있습니다.

### 최고 점수
- 퀴즈를 풀고 최고 점수를 갱신합니다.
- 최고 점수는 JSON 파일에 저장됩니다.
- 프로그램을 종료하고 다시 실행해도 기록이 유지됩니다.

### 입력 및 오류 처리
- 숫자가 아닌 입력을 검사합니다.
- 입력 범위를 벗어난 숫자를 검사합니다.
- 빈 입력을 검사합니다.
- Ctrl+C 입력 시 안전하게 프로그램을 종료합니다.
- JSON 데이터가 손상된 경우 오류를 안내하고 기본 퀴즈로 시작합니다.

## 6. 프로젝트 파일 구조

```text
python-quiz-game/
├── main.py
├── quiz.py
├── quiz_data.py
├── quiz_game.py
├── storage.py
├── state.json
├── README.md
├── .gitignore
└── evidence/
```

### 파일별 역할

- `main.py`: 프로그램 실행 및 메뉴 관리
- `quiz.py`: Quiz 클래스와 정답 판정
- `quiz_data.py`: 기본 퀴즈 8개 제공
- `quiz_game.py`: 퀴즈 진행, 추가, 목록 및 점수 관리
- `storage.py`: JSON 데이터 저장 및 불러오기
- `state.json`: 퀴즈 목록과 최고 점수 데이터
- `README.md`: 프로젝트 사용 및 개발 안내
- `.gitignore`: Git 추적 제외 항목 설정
- `evidence/`: 개발 과정과 테스트 증빙 자료 보관

참고: `.git/`, `__pycache__/` 등 Git 및 Python이 관리하는 폴더는 위 구조에서 생략했습니다.

## 7. 데이터 저장

프로젝트 최상위 폴더의 `state.json`에 퀴즈 목록과 최고 점수를 UTF-8 JSON 형식으로 저장합니다.

저장 파일이 없다면 기본 퀴즈 8개로 프로그램을 시작합니다.

## 8. 실행 및 테스트 결과

다음 기능을 실제 실행하여 확인했습니다.

- 기본 퀴즈 출제 및 점수 계산
- 사용자 퀴즈 추가
- 퀴즈 목록 출력
- 최고 점수 표시
- 프로그램 재실행 후 퀴즈 9개 유지
- 프로그램 재실행 후 최고 점수 89점 유지
- 잘못된 메뉴 입력 처리
- Ctrl+C 안전 종료
- 손상된 JSON 파일 감지 및 기본 퀴즈 복구
- 백업 파일을 사용한 데이터 복원

## 9. Git 및 GitHub 활용

- Git을 사용해 기능별로 개발 내용을 커밋했습니다.
- `feature/quiz-play` 브랜치에서 퀴즈 풀이 기능을 개발했습니다.
- 기능 개발 후 `main` 브랜치로 병합했습니다.
- GitHub 원격 저장소를 사용해 프로젝트 코드를 관리합니다.
