
# Python & Git 기초 퀴즈 게임

## 프로젝트 개요
코디세이 Python 학습 미션을 위한 콘솔 퀴즈 게임입니다.

## 퀴즈 주제와 선정 이유
Python과 Git의 기초 개념을 퀴즈로 복습하기 위해 선정했습니다.

## 개발 환경
- Python 3.10 이상
- 외부 라이브러리 사용 없음

## 실행 방법
프로그램 구현 후 작성합니다.

## 주요 기능
- 퀴즈 풀기
- 퀴즈 추가
- 퀴즈 목록
- 최고 점수 확인
- JSON 파일 저장 및 불러오기

## 프로젝트 파일 구조
기능 구현에 따라 작성합니다.

## 데이터 파일
프로젝트 루트의 state.json에 퀴즈 목록과 최고 점수를 UTF-8 JSON 형식으로 저장합니다.
